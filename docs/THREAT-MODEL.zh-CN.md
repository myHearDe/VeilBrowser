# 威胁模型

## 要保护的资料

- 浏览历史、下载记录、书签和上次会话。
- 密码保险库。
- WebView2 Cookie、LocalStorage、IndexedDB、缓存和站点权限。
- 地址栏和搜索产生的本地记录。

## 能覆盖的攻击

- 浏览器关闭后，其他普通本地用户直接打开数据库或配置文件。
- 把关闭状态下的 VeilBrowser 数据目录复制到另一台电脑后读取。
- 只绕过 WPF 密码界面、但没有正确主密钥的离线读取。
- 修改密文而不被发现：AES-GCM 会进行完整性认证。

## 不能覆盖的攻击

- Windows 管理员、内核驱动、恶意杀毒软件或已控制当前用户会话的木马。
- 浏览器解锁运行时读取工作目录或进程内存。
- 键盘记录、屏幕录制、剪贴板监控。
- 目标网站、网络出口、代理、DNS 服务商本身的记录。
- 浏览器指纹形成的在线关联。
- 异常断电时操作系统尚未写回的资料丢失。

## 密钥结构

1. 程序生成独立随机 256 位数据主密钥。
2. 主密码经 Argon2id 派生出解锁密钥。
3. 解锁密钥只负责用 AES-256-GCM 包裹数据主密钥，因此以后更改主密码不需要
   重新加密整个浏览器配置。
4. 不设置浏览器密码时，数据主密钥由 Windows DPAPI `CurrentUser` 保护。
5. 运行结束后清零托管数组是尽力而为；垃圾回收、交换文件和崩溃转储仍属于剩余
   风险。

## 配置容器

WebView2 使用普通工作目录运行。关闭顺序为：停止浏览器控件 → 等待 Edge WebView2 子进程
→ 保存加密状态 → 压缩配置目录 → 分块 AES-256-GCM 加密 → 原子替换旧容器 →
删除工作目录。

每个 1 MiB 块使用独立派生 nonce 和认证标签，既避免把整个配置读入内存，也能
检测截断与篡改。

## 发布前必须完成的工作

- 在真实 Windows 10/11 x64 上执行安装、升级、崩溃和断电恢复测试。
- 对加密容器、密钥迁移、路径穿越和异常清理做独立安全审计。
- 建立每月 WebView2 SDK、Edge WebView2 Runtime 安全升级流程。
- 关闭或脱敏崩溃转储，给发布文件进行 Authenticode 签名。
- 增加恢复密钥或经过验证的导出备份流程后，再向普通用户承诺可恢复性。
